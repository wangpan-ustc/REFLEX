# Changelog

## 0.2.0

- Core REFLEX framework: Vision Critic / Text Actor (`MDCOrchestrator`), BM25 Skill Memory, UCB1 operator bandit, elitist population, and CEM constant refinement.
- Task runners and Behavioral Evidence renderers for Acrobot-v1, Pendulum-v1, LunarLander-v3, and concentric circular antenna array (CCAA) synthesis.
- Strict 36-D CCAA benchmark scripts and CPU-only classical baselines (Random Search, CMA-ES, GA, PSO).
- OpenAI-compatible multimodal client with environment-variable configuration and credential redaction.
- Offline unit test suite and GitHub Actions CI workflow.
